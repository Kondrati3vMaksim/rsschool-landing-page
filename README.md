# Coffee House — сайт кофейни

Учебный проект RS School: адаптивный сайт кофейни с главной страницей, каталогом и выбором параметров продукта.

[Демо](https://kondrati3vmaksim.github.io/rsschool-landing-page/) · [Исходный код](https://github.com/Kondrati3vMaksim/rsschool-landing-page/tree/landing-page-part-2)

**Автор реализации:** Максим Кондратьев. Использован учебный макет. Актуальный код находится в ветке `landing-page-part-2`; в `main` размещено описание.

## Технологии

JavaScript, HTML5, CSS3, Flexbox, Grid, media queries, DOM API, Fetch API, localStorage. Макет — Figma. Без фреймворков и сборщика.

Каталог загружается через fetch из локального `products.json`. Внешнего API, серверного заказа и оплаты в проекте нет.

## Что реализовал

- Сверстал главную страницу и каталог по макету; адаптировал интерфейс для небольших экранов, использовал Flexbox и Grid.
- Добавил мобильное меню с блокировкой прокрутки, закрытием по Escape и при выборе ссылки.
- Реализовал загрузку JSON, создание карточек товаров и переключение категорий каталога.
- Реализовал модальное окно продукта: описание, изображение, размеры и добавки, пересчёт итоговой цены.
- Добавил закрытие модального окна по кнопке, фону и Escape, а также переключение темы с сохранением в localStorage.

В проекте также есть карусель со стрелками и свайпами. Её реализацию выполнял с помощью ИИ; это отдельная область дальнейшего самостоятельного изучения.

## Пользовательский сценарий

Посетитель открывает каталог, выбирает категорию и продукт. В модальном окне может изменить размер и добавки и увидеть новую цену. Это демонстрация интерфейса выбора продукта, без оформления реального заказа.

## Результат и выводы

Создан сайт из двух страниц с адаптивной вёрсткой и интерактивным каталогом. Связал данные JSON, DOM и состояние выбранного продукта; при изменении параметров цена пересчитывается в интерфейсе. Отдельно отработал управление мобильным меню, модальным окном и прокруткой страницы.

## Локальный запуск

Требования: Git, современный браузер; для команды ниже — Python 3. npm и сборка не нужны.

```bash
git clone --branch landing-page-part-2 --single-branch https://github.com/Kondrati3vMaksim/rsschool-landing-page.git
cd rsschool-landing-page
python3 -m http.server 8080
```

Главная: [http://localhost:8080](http://localhost:8080). Каталог: [http://localhost:8080/catalog.html](http://localhost:8080/catalog.html).

Альтернатива — Live Server в VS Code. Запускайте через HTTP-сервер: каталог использует fetch, поэтому `file://` не подходит.

## Структура

| Файл / каталог | Назначение |
